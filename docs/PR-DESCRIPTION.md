## Summary

The portfolio previously buried selected work below the detection example and presented sample telemetry as though it were completed lab evidence. This change puts projects immediately after the summary, labels the detection material as illustrative, and applies the approved Incident File palette and hierarchy while preserving all project facts, attribution, captions and original assets.

- Apply all 28 approved content and movement entries, explicit Day/Night and homepage Skim/Read controls, natural image framing and direct full-size evidence links.
- Repair inherited terminal command dispatch, keyboard focus, sticky-header anchors, reading-position preservation and mobile table/technical reflow.
- Bound responder playback with Replay; freeze animation clocks and CSS frames while paused, offscreen or hidden; respond to live reduced motion. Terminal cards now advance manually.
- Retain the rendered experiment winners: no grain, a limited 120px build-section rail, and the desktop text/evidence split.

## Validation

Nine runtime tests pass. Browser geometry and viewport screenshot review covered 16 homepage and 24 case configurations at 390, 768, 1280 and 1440px, followed by 320px checks for all five pages in both themes and no-JavaScript checks in both OS themes. Manual pause/frame freezing, offscreen pause, live reduced motion, anchor focus, section-relative mode switching and visible keyboard focus were checked. The final 320px console regression confirms its first and last rows remain reachable by keyboard. Source review confirms preserved assets/factual boundaries, valid local destinations, no nested anchors and no heading skips.

Fifteen of sixteen public links returned HTTP 200; LinkedIn blocked automated verification with 405/999. Physical devices and screen readers were not tested; this is not a full WCAG or performance audit.
